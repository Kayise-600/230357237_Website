Geo Scan Attendance Pro

Project Introduction

Geo Scan Attendance Pro is a smart web-based attendance management system designed to improve the accuracy, reliability and efficiency of student attendance recording.

The system uses dynamically generated QR codes together with GPS-based location verification. Students scan a QR code during a lecture, and the system verifies whether the student is within the authorised location before recording attendance.

Problem Statement

Traditional attendance systems can be time-consuming and may allow students to record attendance on behalf of other students. This can result in inaccurate attendance records and make it difficult for lecturers to monitor student attendance effectively.

Aim of the Project

The aim of Geo Scan Attendance Pro is to develop a secure and efficient attendance system that uses QR code scanning and geolocation verification to record student attendance accurately.

Project Objectives

  • Generate time-limited QR codes for attendance.
  • Allow students to scan QR codes to record attendance.
  • Verify the geographical location of students.
  • Reduce proxy attendance and fraudulent check-ins.
  • Provide lecturers with real-time attendance records.
  • Generate attendance reports and analytics.

Main Features

  1. User registration and login
  2. Student attendance management
  3. Dynamic QR code generation
  4. QR code validation
  5. GPS and geolocation verification
  6. Attendance reporting and analytics
  7. Administrator dashboard
  8. Notifications and messaging

System Users

The system will support different users with different responsibilities.

  • Students: Scan QR codes and record their attendance.
  • Lecturers: Generate attendance sessions and monitor student attendance.
  • Administrators: Manage users, attendance records and system reports.

Technology Stack

  • Frontend: HTML, CSS, JavaScript and React
  • Backend: Django and Python
  • Database: PostgreSQL
  • Version Control: Git and GitHub
  • Web Servers: Apache and Apache Tomcat
